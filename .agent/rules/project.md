# Project rules (Antigravity)

Follow `AGENTS.md` at the repository root: it is the single source of instructions for every agent on this project.
Before working, read `docs/agents/KNOWLEDGE.md` (verified facts) and `docs/agents/OPEN_ISSUES.md` (what is open / taken).
Tools (MinGW gcc in C:\msys64\mingw64\bin, REA MCP, capture scripts): `docs/agents/TOOLS.md`.
After working: add verified facts to KNOWLEDGE.md, a dated entry to `docs/agents/WORKLOG.md`, and update OPEN_ISSUES.md.
